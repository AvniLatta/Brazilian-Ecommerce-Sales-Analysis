BRAZILIAN ECOMMERCE SALES ANALYSIS

* PROJECT OVERVIEW

This project presents an end-to-end data analytics solution using the Brazilian Olist E-Commerce dataset. The objective was to analyze sales performance, customer purchasing behavior, payment preferences, product category performance, and geographic distribution of orders. The project includes data cleaning, SQL analysis, data modeling, dashboard development, and business insight generation using Python, Google Colab, SQL, Tableau, and GitHub.

* BUSINESS OBJECTIVE

The objective of this project is to answer key business questions and provide actionable insights by analyzing e-commerce data.
The analysis focuses on:
Which product categories generate the highest revenue?
Which Brazilian states contribute the highest number of orders?
How have monthly revenue and order volumes changed over time?
Which payment methods are most commonly used by customers?
How are customer review scores distributed?

* KEY BUSINESS INSIGHTS

Health and Beauty generated the highest revenue among all product categories.
São Paulo recorded the highest number of customer orders.
Credit Card was the most frequently used payment method.
Most customers provided five-star reviews, indicating high customer satisfaction.
Revenue and order volume showed an overall increasing trend during the analysis period.
