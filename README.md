BRAZILIAN ECOMMERCE SALES ANALYSIS

* PROJECT OVERVIEW

This project presents an end-to-end data analytics solution using the Brazilian Olist E-Commerce dataset. The objective was to analyze sales performance, customer purchasing behavior, payment preferences, product category performance, and geographic distribution of orders. The project includes data cleaning, SQL analysis, data modeling, dashboard development, and business insight generation using Python, Google Colab, SQL, Tableau, and GitHub.

* BUSINESS OBJECTIVE

The objective of this project is to answer key business questions and provide actionable insights by analyzing e-commerce data.

* DATASET

Dataset Name: Brazilian Olist E-Commerce Public Dataset
Source: Kaggle

The dataset contains customer information, order details, product information, payment methods, customer reviews, and geographic data used to perform business analysis.

* DATA CLEANING AND PREPARATION

The following preprocessing steps were performed before visualization:
Handled missing values,
Removed unnecessary columns,
Verified data consistency,
Prepared cleaned datasets for analysis,
Created relationships between multiple tables in Tableau,
Validated data before dashboard development

* SQL ANALYSIS

SQL was used to explore and validate the dataset before visualization.
